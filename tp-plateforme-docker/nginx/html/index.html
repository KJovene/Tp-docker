TP Docker

Mini plateforme Docker prete a l'emploi

Cette stack locale regroupe un reverse proxy Nginx, un backend whoami, un tableau de supervision Uptime Kuma, un visualiseur de logs Dozzle et un service Redis interne.

Services

  • Nginx : point d'entree principal sur le port 8080
  • Whoami : backend de test affiche conteneur, IP et headers HTTP
  • Uptime Kuma : supervision et checks HTTP
  • Dozzle : consultation centralisee des logs conteneurs
  • Redis : service interne non expose

URLs d'acces

  • Accueil Nginx
  • Whoami via reverse proxy
  • Uptime Kuma
  • Dozzle

Reseaux et persistance

  • front_net : exposition web et observabilite
  • back_net : communication interne applicative
  • Volumes : kuma_data, redis_data, nginx_logs

Point de verification rapide : ouvrez /whoami pour valider le reverse proxy et utilisez Uptime Kuma pour monitorer `nginx` et `whoami`.
